# Kanpur Elite Dolls - Premium Doll Delivery Service Website

A modern, professional, and SEO-optimized website for premium doll delivery services in Kanpur. Built with React, Tailwind CSS, and modern web technologies.

## 🎯 Project Overview

This website showcases a premium doll delivery service with a focus on luxury aesthetics, user experience, and search engine optimization. The design emphasizes discretion, quality, and professional service.

## ✨ Key Features

### Design & User Experience
- **Luxury Minimalism Design**: Sophisticated burgundy and charcoal color scheme with gold accents
- **Premium Typography**: Playfair Display for headlines, Poppins for body text
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices
- **Smooth Animations**: Professional transitions and hover effects
- **Accessibility**: WCAG AA compliant for inclusive user experience

### Functionality
- **Product Showcase**: Grid display of premium doll collection with booking options
- **Service Areas**: Clear display of all delivery locations in Kanpur
- **Customer Testimonials**: Social proof with 5-star reviews
- **Contact Integration**: Direct phone and WhatsApp booking links
- **Floating WhatsApp Button**: Quick access to messaging service
- **Sticky Navigation**: Easy access to all sections while scrolling

### SEO Optimization
- **Meta Tags**: Comprehensive title, description, and keywords
- **Open Graph Tags**: Optimized for social media sharing
- **Structured Data**: Proper semantic HTML for search engine crawling
- **Robots.txt & Sitemap**: Guides search engines through the site
- **Local Keywords**: Optimized for "doll delivery Kanpur" and related searches
- **Mobile-First Design**: Critical for modern search engine rankings

## 🏗️ Technical Stack

- **Frontend Framework**: React 19 with TypeScript
- **Styling**: Tailwind CSS 4 with custom theme
- **Routing**: Wouter for client-side navigation
- **UI Components**: shadcn/ui with Radix UI primitives
- **Icons**: Lucide React for consistent iconography
- **Build Tool**: Vite for fast development and optimized builds
- **Package Manager**: pnpm for efficient dependency management

## 🎨 Design Philosophy

The website follows a **Luxury Minimalism** aesthetic with the following principles:

- **Elegance Through Restraint**: Every element serves a purpose
- **Premium Material Language**: Deep jewel tones with subtle textures
- **Sophisticated Hierarchy**: Clear visual distinction through typography and spacing
- **Timeless Professionalism**: Current design that won't date quickly

### Color Palette
- **Primary**: Burgundy (#8B3A62) - Conveys luxury and sophistication
- **Secondary**: Rose (#E8B4C8) - Softer, approachable accent
- **Accent**: Gold (#D4AF37) - Premium highlights
- **Background**: Cream (#F5F1ED) - Warm, inviting base
- **Text**: Charcoal (#1a1a1a) - Professional, readable
